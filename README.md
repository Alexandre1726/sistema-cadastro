# Sistema de Cadastro

## Objetivo
Sistema simples para cadastrar e consultar usuários, desenvolvido na disciplina
Engenharia de Software I para aplicar gestão de configuração, Git e documentação técnica.

## Funcionalidades
- Cadastro de usuários
- Consulta de registros

## Tecnologias
- Python 3.10+
- Armazenamento em arquivo JSON

## Como executar
```bash
python src/cadastro.py
```

## Documentação
Requisitos e diagramas estão na pasta [docs/](docs/).

### Pré-requisitos
- Python 3.10 ou superior instalado

### Executar os testes
```bash
python -m unittest discover -s testes
```
